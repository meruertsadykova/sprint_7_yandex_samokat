# API-Тестирование сервиса доставки

## 📌 Описание

Проект представляет собой автоматизацию тестирования API сервиса доставки. Проверяются сценарии создания и авторизации курьера, оформления заказа и получения списка заказов.

Используемый стек: **Java, JUnit4, Rest Assured, Allure**.

---

## 🔧 Проверяемые сценарии

### 🚴‍♂️ Создание курьера

- Можно создать курьера с валидными данными.
- Нельзя создать двух курьеров с одинаковым логином.
- Обязательные поля: логин, пароль, имя — без них создание невозможно.
- Запрос возвращает корректный код ответа (`201` при успехе).
- Успешный запрос содержит `ok: true`.
- При отсутствии одного из обязательных полей возвращается ошибка (`400`).
- При повторном использовании логина возвращается ошибка (`409`).

### 🔐 Авторизация курьера

- Курьер может авторизоваться с валидными данными.
- Необходимо передавать обязательные поля: логин и пароль.
- При неверном логине или пароле возвращается ошибка (`404`).
- При отсутствии обязательных полей возвращается ошибка (`400`).
- Успешный ответ содержит `id`.

### 📦 Создание заказа

- Можно указать один из цветов: `BLACK` или `GREY`.
- Можно указать оба цвета.
- Можно не указывать цвет вовсе.
- Ответ содержит информацию о `track`-номере заказа.
- Для тестирования используется параметризация.

### 📋 Получение списка заказов

- Запрос возвращает список всех доступных заказов.
- Ответ содержит массив заказов с параметрами.

---

## 📊 Отчет Allure

- Генерируется Allure-отчет с результатами тестов.
- Включает подробности каждого шага, статус выполнения и ошибки.
- Используется для визуального анализа стабильности системы.

---

## 🛠️ Технологии

- Java 11+
- JUnit 4
- Rest Assured
- Allure Framework
- Maven или Gradle

---

## 🚀 Запуск тестов

1. Установите зависимости:
   ```bash
   mvn clean install

2. Запустите тесты:
   ```bash
   mvn test

3. Сформируйте Allure-отчет:
   ```bash
   allure serve target/allure-results
